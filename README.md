# Yusuf Eren Dölek

Mechanical engineer turned AI engineer. I started out modelling control loops and listening to vibration signals from CNC machines. Today I build systems that let language models answer questions from real documents.

### What I work on
Retrieval-augmented generation, LLM evaluation, and the unglamorous parts that make them hold up in production: document ingestion, chunking.

### What I've learned along the way
- Most of the hard problems in RAG sit before the model: how documents are read, split and kept up to date.
- An answer you can't measure is an answer you can't improve. I keep a fixed set of questions and check every change against it.
- Sometimes the best LLM feature is removing the LLM. If a simple rule does the job, it's cheaper, faster and easier to trust.
- Switching fields taught me that people care about what you've built, not where you started.
- Graph-based retrieval and knowledge graphs, for questions a flat search can't answer
- Evaluating agents that plan and use tools, not just single answers
- Writing my own MCP servers
- AI for physical systems, where my engineering background meets what I do now
